# 📌 Project Overview

**Rising Waters – Flood Prediction System** is a Machine Learning-based web application developed to predict the likelihood of floods using historical weather and environmental data. The project follows a complete Data Science workflow, including data collection, exploratory data analysis, preprocessing, model building, evaluation, and deployment through a responsive Flask web application.

The application enables users to input weather-related parameters and instantly receive a prediction indicating whether flood conditions are likely.

---

# 🎯 Objectives

- 🌧️ Collect and analyze historical flood-related data.
- 📊 Perform data preprocessing and feature engineering.
- 🤖 Train multiple Machine Learning models.
- 📈 Compare model performance and select the best-performing model.
- 🌐 Deploy the trained model using Flask.
- ⚡ Provide real-time flood prediction through an interactive web interface.
