# Epic 2 - Data Visualization and Analysis

## Objective

The objective of this phase is to analyze and visualize the flood prediction dataset to understand its structure, patterns, and relationships before building machine learning models.

## Tasks Completed

- Imported required Python libraries.
- Loaded the flood prediction dataset.
- Displayed the first five rows of the dataset.
- Checked dataset shape and column names.
- Displayed dataset information.
- Performed descriptive statistical analysis.
- Performed univariate analysis using:
  - Histogram
  - Count Plot
  - Box Plot
- Checked missing values.
- Generated a correlation heatmap.
- Saved all visualization outputs as PNG images.

## Output Files

- temperature_distribution.png
- flood_distribution.png
- temperature_boxplot.png
- correlation_matrix.png
- confusion_matrix.png

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Conclusion

The dataset was successfully explored and visualized. The generated graphs help in understanding the distribution of data, relationships between features, and data quality, providing a strong foundation for the preprocessing and machine learning stages.
