# Epic 1 - Data Collection

## Objective

The objective of this phase is to collect the dataset required for developing the Flood Prediction Analysis project.

## Dataset

The dataset used in this project is:

- flood dataset.xlsx

The dataset contains various meteorological features such as rainfall, cloud cover, humidity, temperature, and other environmental variables that are useful for predicting flood occurrences.

## Source

The dataset was downloaded from the project resource link provided in SkillWallet.

## Purpose

The collected dataset serves as the foundation for all later stages of the project, including:

- Data Visualization
- Data Pre-processing
- Model Building
- Application Development
